# Definition of Ready (DoR)

準備完了の定義 - ユーザーストーリーがスプリントに取り込まれるための基準。

## ユーザーストーリー

- [ ] ユーザーストーリーが明確に記述されている
  - As a [ユーザータイプ]
  - I want [達成したいこと]
  - So that [得られる価値]
- [ ] ストーリーが独立している（他のストーリーに依存しない）
- [ ] ストーリーがスプリント内で完了可能なサイズ

## 受け入れ条件

- [ ] 受け入れ条件が明確に定義されている
- [ ] Given/When/Then形式で記述されている
- [ ] テスト可能な条件になっている
- [ ] プロダクトオーナーが確認済み

## 見積もり

- [ ] ストーリーポイントが見積もられている
- [ ] チーム全員が見積もりに合意している
- [ ] 1スプリントで完了可能な見積もり（13ポイント以下推奨）

## 依存関係

- [ ] 技術的な依存関係が特定されている
- [ ] 外部依存関係が特定されている
- [ ] ブロッカーがないか確認済み
- [ ] 依存関係が解決済み、または解決の目処が立っている

## 設計・UI

- [ ] 必要な設計が完了している（該当する場合）
- [ ] UIモックアップ/ワイヤーフレームがある（該当する場合）
- [ ] デザインがレビュー済み（該当する場合）

## 技術的な準備

- [ ] 技術的なアプローチが決まっている
- [ ] 必要なAPIの仕様が明確
- [ ] データモデルが設計されている（該当する場合）
- [ ] 技術的なリスクが特定されている

## 仕様書（新機能の場合）

- [ ] PRDが作成されている
- [ ] 要件がPRDスキーマに準拠している
- [ ] プロダクトオーナーの承認を得ている

## チェックリスト

### 必須項目
- [ ] ユーザーストーリーが明確
- [ ] 受け入れ条件が定義されている
- [ ] 見積もりが完了している
- [ ] 依存関係がクリア

### 推奨項目
- [ ] UIデザインがある
- [ ] 技術設計がある
- [ ] テストアプローチが決まっている
