# Definition of Done (DoD)

完了の定義 - ユーザーストーリーが「完了」と見なされるための基準。

## コード品質

- [ ] コードが実装されている
- [ ] コードがコーディング規約に準拠している
- [ ] リントエラーが0件
- [ ] 型エラーが0件
- [ ] コードフォーマットが統一されている

## テスト

- [ ] ユニットテストが作成されている
- [ ] 統合テストが作成されている（必要な場合）
- [ ] 全てのテストが通過している
- [ ] コードカバレッジが80%以上
- [ ] エッジケースがテストされている

## セキュリティ

- [ ] セキュリティスキャンを通過
- [ ] 依存関係の脆弱性チェックを通過
- [ ] シークレットがハードコードされていない
- [ ] OWASPガイドラインに準拠（該当する場合）

## レビュー

- [ ] セルフレビューが完了
- [ ] コードレビューが完了（2名以上）
- [ ] レビューコメントが対応済み

## ドキュメント

- [ ] コードにコメントが適切に記載されている
- [ ] APIドキュメントが更新されている（該当する場合）
- [ ] READMEが更新されている（該当する場合）
- [ ] 変更履歴が記録されている

## 仕様書（新機能の場合）

- [ ] PRDが作成/更新されスキーマ検証を通過
- [ ] SRSが作成/更新されスキーマ検証を通過
- [ ] Test Specが作成/更新されスキーマ検証を通過
- [ ] トレーサビリティが確保されている

## 受け入れ条件

- [ ] 全ての受け入れ条件を満たしている
- [ ] プロダクトオーナーの承認を得ている（該当する場合）

## CI/CD

- [ ] CIパイプラインが全て成功
- [ ] Quality Gateを通過
